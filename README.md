# Дневник беременности

Личный дневник веса и обхвата талии. Данные хранятся в браузере.

## Локально

```bash
npm install
npm run dev
```

Откройте `http://localhost:5173/pregnancy-diary/`.

## GitHub Pages

1. Репозиторий должен называться `pregnancy-diary`. Если имя другое, поменяйте `REPO_NAME` в `vite.config.ts`.
2. Settings → Pages → Source: **GitHub Actions**.
3. Запушьте ветку `main`. Workflow соберёт `dist` и опубликует сайт.

## Телефон

Откройте опубликованный сайт в браузере телефона и добавьте его на домашний экран: в Safari «На экран Домой», в Chrome «Установить приложение». После этого дневник открывается офлайн.
